## Premium 和 Global 不是一回事

Lightlayer 的新加坡产品分优化线路（Premium）和国际线路（Global）两套网络。带 VP 的型号走 Premium，带 VG 的走 Global。

Premium 面向中国大陆方向做了优化，走的是下面要说到的 CN2、AS4837、CMIN2 这些链路。Global 是国际互联线路，公开资料里没有它的三网回程走向记录，也就没法判断国内访问质量。你如果主要给中国大陆用户用，或者自己从国内连过去操作，优先看 Premium；如果服务对象本身在东南亚或欧美，Global 的价格一样、带宽标称也一样，可以作候选。两款 $7/月的 Premium 机型（SG-VP02、SG-VP04）与 Global 的 SG-VG04 定价相同，选错线路不会多花钱，但会影响速度。

## 三网实际怎么走

2025 年 5 月一篇针对优化线路机型的测评记录了完整的三网往返路径，这是目前能找到的最细的一份数据。

去程方面，电信走 CN2 直连新加坡，联通直连新加坡（AS4837 加 AS10099），移动走 CMIN2 直连。三条都是直连，没有绕道。

回程值得单独说。电信从新加坡先连到电信香港的 CN2 节点（AS4809），再经 CTG/CN2 回内地；联通直接连到联通香港节点（AS10099），再经 AS4837 回内地；移动的回程是从新加坡连到电信香港 CN2 节点（AS4809），再走 CTG/CN2 回来。也就是说，移动用户回国这一段借的是电信的 CN2 链路，而不是走移动自家的 CMIN2。

这一点对移动宽带用户可以当参考：去程 CMIN2、回程 CN2，两个方向都不差，但回程质量取决于电信那一段线路的状态，和纯 CMIN2 双程的产品不是同一种表现。同一篇测评的结论是“三网往返全部直连”，夜间高峰的具体带宽和延迟数值在公开摘录里没有保留，这里就不给数字了。另一家测评站在 2025 年 10 月对 SG-VP04 的评价是线路表现不错，短板在带宽偏小和磁盘 I/O。

## 10M 不限流量和 20M/1TB，算一下就知道选哪个

把带宽换算成实际吞吐：10Mbps 约等于 1.25MB/s，20Mbps 约等于 2.5MB/s。

1TB 是 1024GB，也就是 1,048,576MB。以 2.5MB/s 满速跑，全部用完需要约 419,430 秒，折合约 116 小时，也就是 4.8 到 4.9 天。摊到一个自然月里，平均每天能用的额度约 34GB。

所以判断规则很简单：**平均每天流量跑不到 34GB，选 SG-VP04**，你能拿到双倍带宽，网页打开和文件传输都快一倍；**平均每天超过 34GB，选 SG-VP02**，10M 不限流量按月满速估算可以跑到 3TB 以上，不用盯着流量表。把 34GB/天 反推成平均带宽大约是 3.2Mbps，业务长期占用超过这个水平，1TB 一定不够。

建站、跑 API、远程桌面、偶尔传大文件，实际平均占用通常远低于 3Mbps，SG-VP04 的 20M 峰值体验更好。做中转、挂下载、跑持续同步，直接上 SG-VP02。

## 已知限制，以及不适合谁

几项在使用中会碰到的限制，先列出来。

**不支持 IPv6。** 2025 年 5 月的测评明确记录了这一点，如果你的业务需要 IPv6 地址或要跑 IPv6 -only 的服务，这款直接排除。

**单台 VM 的磁盘 I/O 被官方限制。** 测评实测约 221MB/s，官方对硬盘 I/O 设有上限，目的是防止单台滥用。第三方测评对这类机型的概括是磁盘表现偏弱。跑高并发数据库、需要持续高 IOPS 的应用不适合放在这里。

**CPU 是 E5-2678v3**，上一代平台，单核性能不能和新的 EPYC 或至强可扩展系列比。轻量建站、代理、API 没问题，计算密集型任务要另找。

**带宽天花板不高。** 优化线路可选的带宽区间是 10Mbps 到 50Mbps，做视频分发、大文件下载站这类吃带宽的业务，这个上限会先成为瓶颈。

**不适合谁：** 需要 IPv6 的、需要高磁盘 IOPS 的、需要百兆以上带宽的、以及只想要亚洲低延迟建站且完全不在意 IP 归属却准备买原生 IP 线的人。最后这类需求用 $7 的 SG-VP02 或 SG-VP04 就行。
